# Koan updates

Downloads and the update feed for [Koan](https://github.com/KadenThomp36/koan-updates/releases/latest), a macOS web browser.

- **Download:** the latest `.dmg` is under [Releases](https://github.com/KadenThomp36/koan-updates/releases/latest).
- **Updates:** Koan checks `appcast.xml` in this repository. Every update is signed, and Koan verifies the signature before installing.

Requires macOS 26 or later.
